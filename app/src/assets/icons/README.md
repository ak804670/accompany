# Accompany SVG Icon Pack

Brand direction derived from the supplied Accompany Brand Identity Showcase.

Primary gradient:
- #F05A8A
- #D93673

Dark plum:
- #241B2A

All files are standalone SVGs with no external assets or fonts.

Suggested React Native usage:
- react-native-svg
- import SvgXml from react-native-svg if loading raw SVG strings
- or convert these assets into components using SVGR

Files are intentionally independent so the icon set can be replaced or
extended without changing application UI code.
